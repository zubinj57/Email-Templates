To set up the Hilton PEP/HotelKey integration, we will need to obtain some historical and current data exports from the system. Below are the details on the specific reports we need, along with instructions on how to export them.

A. Onboarding Reports (From Dynamic Reports)

Note: These onboarding reports are to be sent just once during the initial setup phase. We do not need these reports on a recurring basis.
Export steps (apply to each batch):
  1. Run the report
  2. Make sure Show Grand Total is UN-CHECKED
  3. Click the Export icon
  4. Select export type as CSV
  5. Ensure Group By Views are UN-CHECKED and All Columns are SELECTED
  6. Click Export
  7. Rename the file to the date range for identification (examples shown below)
  8. Repeat for the next batch

a. Booked Reservations

Note: Booked Reservations allows date ranges for up to 94 days only. Please export in the following batches.
Suggested naming example: Dec2025_Feb2026.csv
